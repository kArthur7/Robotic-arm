##Robotic Arm CAD Project
**Designer:** Kelvin Arthur

**Software:** SolidWorks 

**Type:** Self Initiated Engineering Project

##Overview
This project is a fully modeled robotic arm that I designed and assembled completely from scratch in SolidWorks. Every component was created individually, then integrated into a functional multi joint assembly using mate constraints and core CAD features. The goal was to build real mechanical design experience outside of coursework and strengthen my CAD fundamentals.

##Features
* Full multi joint robotic arm assembly
* All components modeled independently
* Functional assembly using mates and geometric constraints
* Uses extrude, revolve, cut, fillet, and other core SolidWorks tools
* Demonstrates mechanical intuition and part to part relationships
* Relevant to R&D, prototyping, and medical device design workflows
  
##Repository Structure
* Assembly/ Contains the full SolidWorks assembly file (.SLDASM).
* Parts/ Contains all individual part files (.SLDPRT) used to build the robotic arm.
* README.md Project overview, features, and structure.
  
##Purpose
I completed this project independently to build hands on experience with CAD modeling, mechanical design, and assembly structure. It serves as a portfolio piece for engineering internships and R&D roles, showing my ability to design components from scratch and assemble them into a working system.

##Usage
If you have SolidWorks installed, you can open the assembly file directly to view the full robotic arm and explore each part.
